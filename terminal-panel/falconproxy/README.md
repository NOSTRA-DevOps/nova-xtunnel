# Dossier falconproxy/ (binaires embarqués, optionnel)

Placez ici les binaires Falcon Proxy pré-compilés :

- `falconproxy`      → build x86_64 / amd64
- `falconproxyarm`   → build ARM64 / aarch64
- `VERSION`          → (optionnel) fichier texte avec le numéro de version, ex: `v1.4.2`

Pensez à `chmod +x falconproxy falconproxyarm` avant de packager si vous les ajoutez
manuellement.
